# Icon

Ícones de traço embutidos no bundle, no desenho do Lucide, para usar nas telas sem depender de outra biblioteca.

- `name`: `box`, `mail`, `ruler`, `clock`, `check`, `search`, `plus`, `camera`, `pen`, `building`, `user`, `arrowLeft`.
- Herda tamanho de `font-size` (1em) e cor de `color`. Em botões, passe em `icon` do `Button`.
- No app real, prefira `lucide-react` com os mesmos nomes (`Package`, `Mail`, `Clock`, `Check`, `Search`, `Plus`, `Camera`, `PenLine`, `Building2`, `User`, `ArrowLeft`).
- Sempre decorativo (`aria-hidden`): o texto ao lado carrega o significado.
