# AppBar

Barra superior do app com a marca, o condomínio atual e quem está logado.

- O consumidor fornece `condominio` (nome), `usuario` (nome completo — vira as iniciais do avatar), `perfil` (Porteiro, Responsável, Administrador) e `turno` (Matutino, Vespertino, Noturno).
- `children` entra à direita, antes do usuário: use para um menu ghost ou para trocar de condomínio.
- Sempre no topo de toda tela, 64px de altura, fundo `card` com `border` embaixo.
- O wordmark “iPackage” é texto em `display` com o “i” em `kraft` — enquanto não houver logotipo.
